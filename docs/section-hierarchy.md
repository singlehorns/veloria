# Section Hierarchy

This register records the intended typography structure for current pages and sections.

## Home

| Section | Strength | Main title role | Lead role | Internal headings | Group/Card roles | Text status |
| --- | --- | --- | --- | --- | --- | --- |
| Hero | Emphasis | Brand Display if text is added | None | None | None | Visual-only hero; do not add a second H1 |
| Brand Intro | Emphasis | Page Title | Lead | None | Text link = Button/Text | Current H1 is page-level; content has encoding risk |
| Recommendation | Standard | Section Title | None | Eyebrow/Caption | Product = Card Title, price = Body Secondary | Product card role should match catalog cards |
| Golden Vow Feature | Emphasis | Section Heading Primary | Body | None | CTA = Button | Feature title must stay below Page Title |
| Brand Panel | Supporting | None or Section Heading Secondary | Body | None | CTA = Button | Logo-led body block; avoid oversized body |
| Modern Gent | Standard | Section Title | None | Eyebrow/Caption | Product = Card Title, price = Body Secondary | Carousel product role |
| Celestial Bloom Feature | Emphasis | Section Heading Primary | Body | None | CTA = Button | Feature title must stay below Page Title |
| Collections | Standard | Section Title recommended | None | None | Category = Card Title | Currently missing section-level title |
| Loose Diamonds | Standard | Section Title | None | Eyebrow/Caption | Product = Card Title, price = Body Secondary | Carousel product role |
| Contact CTA | Supporting | Section Heading Secondary | Body | None | Buttons = Button | Common CTA |

## Product Catalog Pages

| Section | Strength | Main title role | Lead role | Internal headings | Group/Card roles | Text status |
| --- | --- | --- | --- | --- | --- | --- |
| Category Sidebar | Supporting | Group Title if heading exists | None | Parent nav = Navigation | Child nav = Navigation secondary | Strong weights should not read as page titles |
| ProductGrid Header | Standard | Page Title on catalog pages, Section Title when embedded | None | Tools = Button/Label | Count = Caption | Must not always render visual/semantic H1 |
| Product List | Standard | None | None | None | Product = Card Title, price = Body Secondary | Card title should be consistent across home/catalog |
| Empty State | Supporting | None | Body Secondary | None | Illustration label = Caption | Keep quiet and centered |
